## 2. 三道门（对应四条已决项）

### P-11 位置约束 = word + pos + require_next + evidence，缺一不算条目

- `pos` 必须是**枚举值**（predicate / adverbial / object / attr / label / other），认不出**不猜，直接拒**
- `require_next` 必须是**能编译的正则字面量**；`/.*/` 这类空壳一律拒（匹配一切 = 没有约束）
- `evidence` 必须是**原文里真能同时命中 word 与 require_next 的那一句** —— 转述句会被拒

> 最后一条是从 W-17 金标集 v0.1 的坑里长出来的：**v0.1 的 text 是转述**，提取器吃原文就误判。
> 尺子的语料必须与提取器输入同口径——现在这条由机器强制，不靠记性。

### P-11+ polarity（墨丘）

断言 / 禁止 / 疑问。**禁止与疑问一律不进档案，只进 `known_fp`**。
本仓实例化：`待办` 标 `polarity: 禁止` —— 任务清单永不进档案。这条本身示范了 polarity 的作用。

### P-12 强制清单（恺 / 墨丘 / 阿轩）

- `known_misses` / `known_fp` **缺失即拒**
- **裸「无」「暂无」拒** —— 「在这批 N 条上没观察到 X」才通过
- **允许空，不允许沉默**：空清单必须带 `_why`
- 绑条数下限；每条须有实测句/证据字段

### 工程契约对齐

- **P1 拒绝要计分**：所有拒收返回结构化 `reasons[]`，逐条列，不静默丢弃
- **P2 身份不许有默认值**：`instance` 缺失即拒
- **metadata 三行制**（阿轩）：`genre / baseline / scope` 缺一 → 「不可被引用」

## 3. 落码时自分校验逮到的两个真错

**① 我自己的枚举漏了「标签位置」。**
第一版 `POS_ENUM` 没有 `label`，把 `待办` 塞进 `other` → 判据当场拒了我。
补 `label` 之后还加了一条一致性判据：**标签位置不得标「断言」**（否则「待办：」被当成事件断言）。

**② `signalOf` 从来没被导出。**
`lib/core/bid-signal.js` 的 `module.exports` 里**没有 `signalOf`** —— 任何外部脚本 require 它都是 `undefined`。
金标集打分器因此只能退回 `detectKind`（只判类别、不抽 peer/direction），三项字段一致率**静默塌成 0%**，看起来像「能力为零」，实际是「接口不认识」。

> 这正是 P1 要防的那类失败：**取不到，却不报错**。已补导出，并在打分器加了显式签名适配（认不出就 exit 3，不静默）。

## 4. 量出来的结果（同一把尺，33 条金标集）

| 提取器 | 精确率 | 召回率 | F1 | kind | peer | direction |
|---|---|---|---|---|---|---|
| 若琢 10-22 版 | 60.9 | **66.7** | 63.7 | **92.9** | 75 | 87.5 |
| **本仓 v2.5（P-11 落码后）** | **100** | 23.8 | 38.4 | 80 | **100** | 66.7 |

**这不是「谁更好」，是两种错误代价取向：**

- 本仓 **FP = 0**：宁可漏，不可脏（对齐 L-2「硬凑会毒化下游」）
- 若琢召回更高：抓得全，但 9 条假阳全是 promise（任务清单被吃进去）

> 真结论在召回一侧：**本仓 FN 16 条**，绝大部分是「关系事件但无标准 kind 动词」（G-15/16 边界样本）。
> 也就是 —— **P-11 确实治住了过判（FP 9→0），但它治不了漏报。**
> 下一步该做的是**召回**（无动词关系事件），不是继续收紧位置约束。

## 5. 用法

```bash
# 校验一份口径声明（三道门）
node csb-memory/lib/core/bid-lexicon.js <declaration.json>

# 金标集打分 + 顺带校验对侧词表合规（同一把尺的两半）

  --goldset data/bid/goldset-ruozhuo-v0.2.json \
  --declaration ../csb-memory/config/bid-declaration-ruolan-v2.5.json
```

合规检查**不改变**准确率数字，单独一行报：`✅/❌ P-11/P-12 合规` —— 准确率与「可不可被引用」是两件事。
